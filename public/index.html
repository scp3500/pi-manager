子代理

打开子代理页 工作区映射

是什么

  • 每个子代理是 E:/pi_agent/pi_config/agents/ 下的一份分类 Markdown（frontmatter + Prompt）
  • 主会话通过 subagent 工具按名称调用；可单跑或 tasks[] 并行
  • 侧栏「工作流」是 pi_config/workflows 里的协作规范（按需 read）

怎么建

  1. 打开子代理页 →「+ 子代理」
  2. 填名称、模型，勾选工具权限
  3. 写清 Prompt：职责、输出格式、边界
  4. 保存后，在 Pi 里让主 Agent 调用该名称

工作流规范需要先在「工作区」映射 memory 目录。

调用示例

# 主 Agent 侧（示意）
subagent · agent: worker · task: "实现登录页"

# 并行
subagent · tasks: [
  { agent: "researcher", task: "查 A" },
  { agent: "researcher", task: "查 B" }
]

工作区 · 路径映射设定

        
root 与 map 路径映射

        

          已保存
          
          
          
        

      

      

        

          
已配置

          

          
建议加入

          

        

        

          

            
在这里设置文件夹对应关系

            
从左侧选一个，或点「+ 工作区」

            
这页做什么：指定本机某个大文件夹（根路径），再用映射告诉程序：里面哪个子文件夹是记忆、哪个是知识库。

            
    
              
  • Pi 标准目录已内置，管模型/子代理等，一般不用删
    • 
              
  • 要用记忆/知识库：点「+ 工作区」→ 填根路径 → 映射里写 "memory":"memory" 等 → 保存
    • 
              
  • 映射值是相对路径（相对根路径），不要写盘符绝对路径
    • 
              
  • 左边「建议」是空的也正常，手动添加即可
    • 
            

            
打开某个工作区后，页面上有「怎么映射？」折叠说明

          

        

        

          

            
—

            

              
            

          

          


          

            怎么映射？（必读）
            

              
一句话：「根路径」= 本机上的大文件夹；「映射」= 告诉程序里面哪一格是记忆、哪一格是知识库。

              
    
                
  1. 根路径：填真实存在的目录，例如 D:/my-pi-lab 或 ~/Documents/pi-lab。
    2. 
                
  2. 在这个目录下建子文件夹（若还没有）：例如 memory、knowledge。
    3. 
                
  3. 映射框里写 JSON：键是用途，值是相对根路径的子目录名（不要写盘符绝对路径）。
    4. 
                
  4. 点右上角保存。下方「映射状态」应显示「存在」。
    5. 
                
  5. 再打开顶栏「记忆」「知识库」——应能看到对应文件夹里的文件。
    6. 
              

              
最小示例（可复制后改路径）

              
{
  "memory": "memory",
  "knowledge": "knowledge"
}

              
含义：根路径/memory → 记忆页；根路径/knowledge → 知识库页。子目录叫别的名字也可以，例如 "memory": "notes" 表示用 notes 当记忆。

              
Pi 标准目录一般只映射 agents/skills，不必硬加 memory。需要笔记时另加一个你自己的工作区即可。
